# LEGO-Animation-Tweaks
Blender-Addon für LEGO-/Stop-Motion-Projekte: fügt Kamera- und Bone-Animationen organisches Noise hinzu, erstellt Stop-Motion-Timing "on 2s" (respektiert Kamera-Marker), setzt Delta-Transforms zurück und patcht Shader-Skalierung (Bevel/Bump/SSS/Noise) für skalierte Assets inkl. Lock-Schutz gegen Mehrfach-Patching.
